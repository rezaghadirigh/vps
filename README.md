# CosmoStore PHP Shop

یک اسکریپت فروشگاه لوازم آرایشی با نصب خودکار، پنل کاربر و پنل مدیریت.

## نصب
1. مخزن را روی هاست خود قرار دهید.
2. مطمئن شوید PHP (نسخه 8 به بالا) و افزونه PDO_SQLite فعال است.
3. پوشه `data/` قابلیت نوشتن داشته باشد.
4. آدرس سایت را باز کنید؛ اگر برای اولین بار است به صورت خودکار به صفحه نصب هدایت می‌شوید.
5. اطلاعات فروشگاه و مدیر را وارد کنید تا پایگاه داده ساخته شود.

## ساختار دایرکتوری
- `index.php`: پنل کاربری و فروشگاه.
- `admin.php`: پنل مدیریت.
- `install.php`: نصاب خودکار.
- `includes/`: توابع و پیکربندی.
- `templates/`: نماهای HTML.
- `assets/`: فایل‌های استایل.
- `data/`: پایگاه داده SQLite و فایل نصب.

## امکانات کاربری (20 قابلیت)
1. ثبت‌نام مشتریان جدید.
2. ورود به حساب کاربری.
3. مشاهده صفحه اصلی و بنرهای تبلیغاتی.
4. لیست محصولات با فیلتر دسته‌بندی.
5. فیلتر محصولات بر اساس برند.
6. جستجوی محصولات.
7. مشاهده جزئیات کامل محصول.
8. افزودن محصول به سبد خرید.
9. بروزرسانی تعداد اقلام سبد خرید.
10. حذف اقلام از سبد خرید.
11. مشاهده خلاصه سبد و تسویه حساب.
12. انتخاب روش ارسال و پرداخت هنگام خرید.
13. مشاهده تاریخچه سفارش‌ها.
14. مشاهده جزئیات هر سفارش و وضعیت آن.
15. مدیریت لیست علاقه‌مندی‌ها.
16. ثبت تیکت پشتیبانی.
17. مشاهده وضعیت و پاسخ تیکت‌ها.
18. بروزرسانی اطلاعات پروفایل.
19. تغییر رمز عبور.
20. ثبت و مشاهده نظرات/امتیاز محصولات.

## امکانات مدیریت (20 قابلیت)
1. داشبورد خلاصه آمار محصولات، سفارش‌ها، کاربران و تیکت‌های باز.
2. گزارش فروش ماهانه.
3. گزارش موجودی محصولات.
4. تاریخچه فعالیت‌ها و لاگ سیستم.
5. مدیریت تنظیمات عمومی فروشگاه (نام، شعار، لوگو، ایمیل پشتیبانی).
6. ایجاد، ویرایش و حذف دسته‌بندی‌ها.
7. ایجاد، ویرایش و حذف برندها.
8. ایجاد، ویرایش و حذف محصولات.
9. مدیریت موجودی و ثبت تغییرات انبار.
10. مشاهده سوابق تغییر موجودی.
11. مدیریت سفارش‌ها و بروزرسانی وضعیت آن‌ها.
12. مشاهده جزئیات اقلام هر سفارش.
13. مدیریت نقش و وضعیت کاربران.
14. پاسخگویی و بروزرسانی وضعیت تیکت‌های پشتیبانی.
15. مدیریت کدهای تخفیف.
16. مدیریت بنرها و کمپین‌های تبلیغاتی.
17. مدیریت روش‌های ارسال و هزینه آن‌ها.
18. مدیریت روش‌های پرداخت و راهنمای پرداخت.
19. مدیریت صفحات محتوایی سایت.
20. دسترسی سریع به نمای فروشگاه و خروج از سیستم.

## توسعه
- تمامی توابع پایگاه داده در `includes/store.php` قرار دارند.
- برای اجرای تست سریع می‌توانید با دستور زیر صحت سینتکس فایل‌ها را بررسی کنید:

```bash
for f in *.php includes/*.php templates/*.php; do php -l "$f"; done
```
